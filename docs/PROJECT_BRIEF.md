# 1. Purpose

This document describes the mission, context, objectives and development principles of the **InvitationGenerator** project. It is the primary context document that OpenCode should study before starting development.

# 2. Project Overview

**InvitationGenerator** is the first module of a future digital assistant for the organizing committee of the interregional project «Физики и лирики».

Its purpose is not simply to generate letters but to support the first stage of professional communication.

# 3. Project Context

The project begins with a large-scale survey of universities and partners. Personalized invitation letters launch this communication process.

# 4. Mission

Reduce the time required to prepare high-quality personalized invitations while preserving professionalism, individuality and consistency.

# 5. Product Role

Workflow:

1. Explain the project.
2. Prepare a personalized letter.
3. Send the invitation.
4. Invite the recipient to complete the survey.
5. Collect feedback.
6. Support further cooperation.

# 6. Target Users

Current MVP:
- Project coordinator.

Future:
- Organizing committee;
- Regional coordinators;
- University representatives.

# 7. Communication Principles

Every generated letter should:
- explain the project;
- explain why the recipient is contacted;
- clearly describe the requested action;
- motivate participation;
- establish trust.

# 8. MVP Scope

The first version must:
- choose a letter type;
- enter recipient data;
- generate a personalized invitation;
- allow editing;
- copy/export the result.

# 9. Future Development

- Template library;
- Word integration;
- Excel import;
- Communication history;
- Analytics.

# 10. Development Principles

1. Practical usefulness.
2. Simplicity.
3. Clear architecture.
4. Scalability.
5. Maintainability.

# 11. Out of Scope

No databases, user accounts, email integration, automatic mailing or CRM in MVP.

# 12. Success Criteria

The MVP is successful if it saves time, produces quality letters and is usable by non-programmers.

# 13. Core Principle

> InvitationGenerator is a real working product, not a technology demonstration.
