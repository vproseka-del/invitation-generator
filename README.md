# InvitationGenerator

> **Digital assistant for the organizing committee of the interregional project «Физики и лирики»**

---

## Project Status

**Current phase:** MVP Design & Initial Development

The project is focused on creating a practical web application that helps prepare personalized invitation letters for universities, partners and experts participating in the communication campaign of the «Физики и лирики» project.

This repository contains both the application and its core design documentation.

---

# Development Philosophy

The goal is **not** to build a technology demo.

The goal is to create a reliable working tool that saves time for the organizing committee and can grow into a complete digital assistant.

Every engineering decision should favor:

- simplicity;
- clarity;
- scalability;
- maintainability;
- practical usefulness.

---
