# Корпус авторских писем

## Назначение

Корпус — это база знаний оригинальных текстов деловой переписки организационного комитета проекта «Физики и лирики».

Корпус служит источником для:

- формирования и уточнения профиля авторского стиля VIV_STYLE;
- анализа стиля, тона и логики изложения;
- улучшения качества генерируемых писем.

## Структура каталога

```text
knowledge/corpus/
├── letters/
│   ├── rector/       # письма ректора
│   ├── committee/    # письма организационного комитета
│   ├── support/      # письма поддержки
│   ├── ministry/     # письма в министерства и ведомства
│   └── other/        # прочие письма
├── index.json        # картотека корпуса
└── README.md         # этот файл
```

## Правила пополнения

1. Письма раскладываются по папкам **по типу автора или документа**, а не по проектам: `rector`, `committee`, `support`, `ministry`, `other`.
2. Каждое письмо — отдельный текстовый файл (предпочтительно `.md` или `.txt`) с корректной кодировкой UTF-8.
3. Имя файла должно быть кратким, понятным и уникальным, например `2025-11-12_приглашение_вуз.md`.
4. После добавления письма его описание вносится в `index.json` (номер, автор, дата, файл, теги, примечания).
5. Не добавляются письма без разрешения на использование и письма, содержащие персональные данные сверх необходимого минимума.
6. `index.json` ведётся вручную и постепенно станет картотекой корпуса; автоматическая обработка не выполняется.
7. После каждого существенного изменения структуры корпуса необходимо обновить CHANGELOG.md проекта.
